FILE 02 / 06

integrate_llg.m

RK4 stages, solver routing, and saved frames

+111 −226

Four field evaluations now surround four derivative evaluations. The evolving spins stay on the GPU; only selected frames are gathered.

  • RK4. The first field is evaluated from Sₙ. Subsequent fields use Sₙ + h·k₁/2, Sₙ + h·k₂/2, and Sₙ + h·k₃. All three components of the entire lattice are supplied at each stage. The result uses weights 1:2:2:1 and is normalized after the combined update.
  • Heun / PC4. The existing Heun and PC4 kernels are retained. PC4 now uses three complete RK4 bootstrap steps and a three-state history carried across chunks.
