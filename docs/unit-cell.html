How the drawing repeats

The six-sided prism contains a central column and six perimeter columns. The perimeter alternates two column groups; the center gives the third. Each column carries a four-site A–D sequence. Adjacent drawn prisms share their corner columns; coincident markers are drawn only once.

The displayed count includes exterior corner columns. It is a count of drawn markers, not a bulk-cell atom count or a claim about surface termination.

How to read the labels

A₁–D₁, A₂–D₂, and A₃–D₃ run from top to bottom within each column sequence, matching the notebook's first figure; c points upward. The numeric illustration coordinates and sequence offsets serve only to construct this schematic. Selecting a marker reports its group, letter, and repetition indices.

These labels have not been assigned to the green/orange/blue/purple/red/black MATLAB masks. The array and exchange explorer remains the source for that code-level mapping.
