Notebook page 8 identifies the same links. dmi.m groups them by layer: nex = i−1 (physical +z), pre = i+1 (physical −z). Bond colors below identify these two groups; atom colors retain their site meaning. An interior atom has nine listed neighbors; surfaces and lateral edges omit missing links.

B_DMI,x = (Dsim / muigpu) (S_nex,y − S_pre,y)
B_DMI,y = (Dsim / muigpu) (−S_nex,x + S_pre,x)
B_DMI,z = 0

DMI-vector arrows: ↑ +Dz on nex links; ↓ −Dz on pre links. Each arrow is the DMI vector for the directed pair from the target to that neighbor, separate from the line connecting the sites. Missing links have no vector arrow.

Sign convention: Eij = Dij · (si × sj) on notebook page 5, with the current Dsim = −4.8065e−23 J in main.m, line 44. Differentiating gives B = (Dz/μs)(−sy, sx, 0), so Dz = −Dsim for nex and Dz = Dsim for pre. Arrow styling follows page 4; only the implemented z component is shown, not a reconstruction of that figure’s full vectors. Implemented field: integrate_llg.m, lines 166–168.
